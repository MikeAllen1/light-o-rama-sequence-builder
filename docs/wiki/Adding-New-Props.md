# A new prop this year

No need to start over. On the start page, **New prop this year?** adds new props to the shows you already have:

- **S5/S6:** choose the finished `.loredit`, then your updated preview with the new props.
- **S4:** add the new channels to the `.lms` in the S4 Sequencer, leave them empty, and choose that file.
- **The song** is optional. Without it, the program reads the song's shape from the sequence itself.

Every prop, effect and setting already in the sequence is copied exactly; only the new props get effects, in the sequence's own style. Wherever the sequence goes dark, the new props stay dark too. The result is a new file: the original is never changed.

It refuses, rather than guessing, when the preview no longer has a prop the sequence uses, or when a prop's number of channels changed.
