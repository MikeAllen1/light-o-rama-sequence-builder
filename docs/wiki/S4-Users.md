# S4 users

S4 has no preview files, so choose one of your own S4 sequences (`.lms`) as the display. Any song you have sequenced for the display will do: only its channels are used.

- Each channel becomes a prop; channel groups are kept.
- The show is saved as a new `.lms` with exactly the same channels.
- Name channels plainly ("Arch 3", "Mini Tree 2", "Roof") so the program can tell what they are.
- The 10-second display test is S5/S6 only.

Any save-file version opens. Details: [S4_FORMAT.md](https://github.com/MikeAllen1/light-o-rama-sequence-builder/blob/master/docs/S4_FORMAT.md).
