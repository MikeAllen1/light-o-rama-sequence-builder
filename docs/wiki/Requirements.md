# Requirements

Requirements are things the show must do on your display. In New show, step 3, choose a requirement, the props it is about (a kind of prop, an S6 group, or individual props) and any details, then **Add**. They are remembered for that display.

| Requirement | Example |
| --- | --- |
| Keep on all song | The star |
| Never use | A prop that is broken or not up this year |
| Keep dark during | The mega tree in the verses |
| Limit brightness to | The mega tree at 60% |
| Keep channels lit with the rest | The star on top of the mega tree lights only with the tree |
| Only these colors | Blue and white on the RGB floods |
| Light when these words are sung | "fire" lights the homemade trees (needs timed lyrics or a word file) |

Every show is checked against your requirements and the built-in rules before it is written; a show that breaks one is never saved.

Ready-made requirement files are in [examples/requirements](https://github.com/MikeAllen1/light-o-rama-sequence-builder/tree/master/examples/requirements), for use with `--rules` on the command line. [RULES.md](https://github.com/MikeAllen1/light-o-rama-sequence-builder/blob/master/docs/RULES.md) lists every rule and the file format.
