# FAQ

**Does it need the internet?**
No. It runs on your computer. It only asks GitHub whether a newer version is out (you can turn that off). See [Privacy and Safety](Privacy-and-Safety).

**Does it use AI to make the show?**
No. Shows are built by the program's own rules from the music analysis and your display, on your computer. The only optional AI feature is typing requirements in your own words, and only if you set up your own Anthropic API key.

**Which Light-O-Rama versions?**
S4, S5 and S6, whatever version saved the file. You need Light-O-Rama to play the shows.

**Which props?**
Standard LOR props (single color, multicolor, channel per color, multi-segment) and non-pixel RGB props. Pixel and DMX props are listed but not sequenced yet.

**Will it change my files?**
Never. Your preview, songs and sequences are only read; every show is a new file.

**Can I edit the show afterwards?**
Yes: in the S6 Sequencer like any sequence, or for quick fixes in the app's workspace.

**Can I sell shows made with it, or sell the program?**
No. It is free to use, copy, change and share, but not to sell (MIT with the Commons Clause; see the [license](https://github.com/MikeAllen1/light-o-rama-sequence-builder/blob/master/LICENSE)).

**Is it from Light-O-Rama?**
No. It is an independent project, not affiliated with or endorsed by Light-O-Rama, Inc.
